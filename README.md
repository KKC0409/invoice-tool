# 开票宝 Pro - 批量开票模板生成工具

> 🧾 一款基于 React 19 的纯前端批量开票工具，支持 Excel 导入导出、智能匹配、数据加密存储。

## ✨ 功能特点

- 📁 **Excel 导入导出** - 支持销售台账、客户库、编码映射的批量导入
- 🤖 **智能匹配** - 自动匹配客户信息和税收分类编码
- 🔒 **数据安全** - AES-256-GCM 加密存储，数据仅存于本地
- 📋 **批量处理** - 一键生成税局格式的批量开票模板
- 📊 **历史记录** - 完整的处理历史，支持搜索和导出
- 🏢 **多账号支持** - 客户多银行账号管理

## 🚀 在线体验

👉 [点击这里直接使用](https://kkc0409.github.io/invoice-tool/)

## 📖 使用方法

1. 双击打开 `index.html` 文件（或点击上方在线链接）
2. 首次使用设置密码
3. 按照引导完成公司信息设置
4. 导入客户库和编码映射
5. 上传销售台账 Excel
6. 一键生成批量开票模板

## 🛠️ 技术栈

- **前端框架**：React 19 + TypeScript
- **状态管理**：Zustand
- **样式方案**：Tailwind CSS
- **Excel 处理**：SheetJS
- **加密方案**：AES-256-GCM + PBKDF2
- **构建工具**：Vite + vite-plugin-singlefile

## 🔐 安全特性

- 本地加密存储（AES-256-GCM）
- PBKDF2 密钥派生（600,000 次迭代）
- 零网络请求，数据不离开本地
- 密码错误5次自动锁定
- 支持数据备份和恢复
